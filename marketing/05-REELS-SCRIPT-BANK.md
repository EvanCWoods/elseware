# 05 — The Reels Script Bank (50 production-ready scripts)

> 50 Reels. Each one is a shootable script. Each one has a hook engineered for 60%+ 3-second hold.

This is the working bank. The 90-day calendar (`04-90-DAY-CONTENT-CALENDAR.md`) tells you the *order*. This file gives you the *exact words*. Pull, shoot, ship.

**Production rules for every script:**
- Hook lives in the first 1.7 seconds. On-screen text + dialogue + visual hook all hit at once.
- Total length: 7–22s unless `[LONG]` (45–60s).
- Final 3s = brand mark `elseware.app` lower-right + caption `one purchase. yours forever.`
- First and last frame visually identical → loop-engineered.
- Captions burned in (always). Style: SF Pro Bold or GT America Medium, white text, 2px black outline at 5% opacity.
- Audio = our soundscape unless explicitly stated. Upload as named original audio so other creators can re-use.

**Pillar key:** `P1` = Lock-In Meme · `P2` = Soundscape POV · `P3` = Place / Aesthetic.

## How to use this bank

1. **Pick a Reel from the calendar (`04-90-DAY-CONTENT-CALENDAR.md`).**
2. **Find the matching script number here** (or use a Day-N adjacent script).
3. **Shoot vertical 9:16, 1080×1920.** iPhone camera + a tripod is enough. Natural light or a single warm bulb.
4. **Edit in CapCut or InShot.** Add captions, layer audio (export from Elseware via screen recording).
5. **Brand mark always lower-right last 3 seconds.**
6. **Loop-engineer the first and last frame.**
7. **Schedule via Meta Business Suite for the slot in the calendar.**

The 50 scripts above + the 40 calendar days they don't yet cover = **90 days of content shipped from this single document.** When you run out of scripts, clone the top 5 by save rate five ways each, swap nouns. That's another 25 Reels with ~5x the conversion of cold-start content.
