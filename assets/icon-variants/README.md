# App Store Icon Variants

For Apple's Product Page Optimization (PPO) test 2 (week 8–11 per `marketing/07-FUNNEL-AND-ASO.md`).

The **control** is the existing icon at `assets/icon.png` (sound-wave ripples + ELSEWARE wordmark) — generated by `scripts/generate-icon.js`. Don't touch the control. We A/B against it.

## Variants

| Variant | File | Hypothesis |
|---|---|---|
| A | `A-serif-e.svg` | A single italic serif "e" on cream is more memorable on a crowded home screen than the literal sound-wave control. Tests *aesthetic identity* > *literal product depiction*. |
| B | `B-place-mosaic.svg` | A 2×3 mosaic of the 6 places telegraphs "this app has 6 different places" pre-emptively. Tests *literal product depiction* > *aesthetic identity*. |

## Convert SVG → PNG

App Store Connect requires PNG. Apple's source size is 1024×1024.

```bash
brew install librsvg
cd assets/icon-variants
for f in *.svg; do
  rsvg-convert -w 1024 -h 1024 "$f" -o "${f%.svg}.png"
done
```

## Upload

In App Store Connect → Product Page Optimization → New Variant:
1. Upload `A-serif-e.png` as Variant A.
2. Upload `B-place-mosaic.png` as Variant B.
3. Allocate traffic 33% / 33% / 34% (control / A / B).
4. Run for at least 14 days. 90% confidence floor before declaring a winner.

## Reading results

Apple reports per-variant **install conversion rate** and **product page views**. The variant with the highest install rate after 14 days at p<0.10 wins. If neither beats control, retain control.

If a variant wins, also update the matching favicon on `elseware.app` and the Instagram profile picture so brand identity stays consistent across the funnel.
